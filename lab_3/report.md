# Отчет по лабораторной работе №3

## Задание
Написать программу на языке C/C++ для перемножения двух матриц с использованием MPI для параллельных вычислений.
Исходные данные: файл(ы) содержащие значения исходных матриц.
Выходные данные: файл со значениями результирующей матрицы, время выполнения, объем задачи.
Обязательна автоматизированная верификация результатов вычислений с помощью сторонних библиотек или стороннего ПО (например на Matlab/Python).

## Реализация
Программа написана на языке C++ с использованием библиотеки MPI (MPICH). Создан класс `Matrix`, реализующий хранение и операции над матрицами, включая распределённое перемножение с передачей блоков данных между процессами.

### Алгоритм работы:
1. Генерация двух случайных матриц на процессе с рангом 0.
2. Распределение строк первой матрицы между процессами.
3. Рассылка второй матрицы целиком всем процессам.
4. Каждый процесс умножает свою часть строк первой матрицы на всю вторую матрицу.
5. Собираются частичные результаты в итоговую матрицу на процессе 0.
6. Результат сохраняется в файл (только для одной размерности из 10).
7. Производится 10 запусков для каждой размерности, рассчитывается среднее время.

### Верификация
Проверка корректности осуществляется путём сравнения результата с эталонным, полученным в Python с использованием `numpy.dot()`.

## Вывод
Использование MPI позволило эффективно распараллелить вычисления. Прирост производительности получился лучше, чем при использовании OpenMP, особенно при работе с большими матрицами. Однако масштабируемость ограничивается накладными расходами на передачу данных и синхронизацию между процессами.  
MPI показал себя как надёжный способ распараллеливания на распределённых системах, особенно при отсутствии общего доступа к памяти.
